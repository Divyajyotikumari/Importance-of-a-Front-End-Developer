# Front-End Developer Guide (Interactive Site)

What this includes:
- `index.html`, `styles.css`, `script.js`
- A button that generates a **3-page PDF** using jsPDF
- A short interactive Q&A quiz

How to use:
1. Open `index.html` in your browser.
2. Click **Download PDF (3 pages)** to generate and save the 3-page PDF.
3. Use the Q&A section to test your knowledge; click **Check Answers** to grade.

Notes:
- The PDF is generated client-side using jsPDF; no server required.
- If you want a static PDF file in the repo, I can generate one and add it to the workspace on request.
